# CafeRevenue

Учебный проект программного модуля управления доходами кафе.

## Возможности

- Вход в систему и смена пользователя.
- Разделение доступа для кассира, управляющего и администратора.
- Открытие и закрытие кассовой смены.
- Создание заказа со столиком или без него.
- Добавление блюд, изменение количества и удаление позиций.
- Автоматический расчёт суммы с сохранением цены на момент заказа.
- Оплата наличными с расчётом сдачи или картой с подтверждением терминала.
- История своих заказов и запрет изменения оплаченных заказов.

## Используемые технологии

C#, WPF, .NET 9, Microsoft SQL Server и Visual Studio 2022.

## Запуск

Открыть решение CafeRevenue.sln в Visual Studio и нажать F5.
Для работы приложения необходима база CafeRevenue в SQL Server.
Настройки подключения находятся в файле appsettings.json.
При установке на новый компьютер SQL-скрипты из папки Database выполняются по порядку номеров.

Для работы с заказами войти как cashier или admin. Учебный пароль: Cafe2026!.
